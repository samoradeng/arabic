## 2. Phone Call Phrases

### Starting a Call

| Arabic | Transliteration | Meaning |
|--------|----------------|---------|
| آلو | aalo | Hello (phone only) |
| مرحبا، مين معي؟ | mar7aba, meen ma3i? | Hello, who is this? |
| أنا [اسم] | ana [name] | This is [name] |
| [اسم] موجود؟ | [name] mawjood? | Is [name] there? |
| ممكن أحكي مع...؟ | mumkin a7ki ma3...? | Can I speak with...? |
| غلط رقم | ghala6 ra2am | Wrong number |

### During a Call

| Arabic | Transliteration | Meaning |
|--------|----------------|---------|
| سمعني؟ | smi3ni? | Can you hear me? |
| مش سامعك منيح | mish saami3ak mnee7 | I can't hear you well |
| ارفع صوتك | irfa3 9ootak | Speak louder |
| استنى / استني لحظة | istanna / istanni la7dha | Wait a moment |
| أعيد؟ | a3eed? | Should I repeat? |
| شو قلت؟ | shu 2ult? | What did you say? |
| خليك عالخط | khalleek 3al-kha66 | Stay on the line |

### Ending a Call

| Arabic | Transliteration | Meaning |
|--------|----------------|---------|
| يلا، باي | yalla, bye | OK, bye |
| بحكيك بعدين | ba7keek ba3dein | I'll call you later |
| سلملي على... | sallimli 3ala... | Say hi to... for me |
| الله معك | allah ma3ak | God be with you |
| خلص، يلا | khala9, yalla | That's it, OK then |

## 3. Phone Call Dialogue

> — آلو؟
> — aalo?

> — آلو، مرحبا. أحمد موجود؟
> — aalo, mar7aba. a7mad mawjood?

> — أنا أحمد. مين معي؟
> — ana a7mad. meen ma3i?

> — أنا مارك. كيفك يا أحمد؟
> — ana Mark. keefak ya a7mad?

> — أهلا مارك! الحمد لله. شو أخبارك؟
> — ahla Mark! il-7amdu lillah. shu akhbaarak?

> — تمام. بس بدي أسألك — بكرة فاضي؟ بدي أتغدى معك.
> — tamaam. bass biddi as2alak — bukra faa9i? biddi atghadda ma3ak.

> — بكرة؟ استنى أشوف... آه، فاضي بعد الساعة وحدة.
> — bukra? istanna ashoof... aah, faa9i ba3d is-saa3a wa7de.

> — تمام! نتلاقى الساعة وحدة ونص عند مطعم هاشم؟
> — tamaam! nitlaa2a is-saa3a wa7de w nu99 3ind ma63am haashim?

> — ماشي! يلا بشوفك بكرة.
> — maashi! yalla bshoofak bukra.

> — يلا باي. سلملي على العيلة.
> — yalla bye. sallimli 3al-3eile.

> — الله يسلمك. يلا باي.
> — allah yisalmak. yalla bye.

## 4. Texting / Chat Arabic — عربيزي

Jordanians text using **3arabizi** (Arabic written with Latin letters and numbers). You already know the number system from the transliteration key.

### Common Text Abbreviations

| Text | Meaning |
|------|---------|
| ahla | أهلا |
| keefk | كيفك |
| il7 | الحمد لله (il-7amdu lillah) |
| isa | إن شاء الله (inshaallah) |
| msa | مع السلامة |
| 3adi | عادي |
| wla yhimk | ولا يهمك |
| hh or ههه | hahaha (laughing) |
| lol | same as English |
| ok or اوكي | OK |
| tbarkallah | تبارك الله |

### Example Text Conversation

```
Ahmad: ahla bro keefk?
You:   il7 tmmam w inta?
Ahmad: mneee7. shu 3m tswi?
You:   wla shi, belbeit. shu fi?
Ahmad: yalla nitzla 3l downtown?
You:   emta?
Ahmad: hssa? sa3a w nos?
You:   yalla isa. wein nitla2a?
Ahmad: 3nd il msjid il 7seini
You:   ok bshoofk
Ahmad: yalla b
```
