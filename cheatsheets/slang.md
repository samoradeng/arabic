# Jordanian Slang Dictionary

Words and phrases you won't find in a textbook but hear every day in Jordan.

---

## Everyday Slang

| Slang | Transliteration | Meaning | Example |
|-------|----------------|---------|---------|
| يا زلمة | ya zalame | dude / man | يا زلمة وينك! — Dude, where are you! |
| يا معلم | ya m3allim | boss / master | يا معلم، قهوة لو سمحت — Boss, coffee please |
| يا عمي | ya 3ammi | bro / uncle | يا عمي ما تزعل — Bro, don't be upset |
| ولك | walak | hey you | ولك تعال! — Hey, come here! |
| فش | fish | there isn't | فش حدا — There's nobody |
| هسا | hassa | right now | هسا بيجي — He's coming right now |
| عادي | 3aadi | normal / it's fine | عادي ما تقلق — It's fine, don't worry |
| خلص | khala9 | done / enough / stop it | خلص، بكفي — Enough, that's enough |
| طز | 6uzz | screw it / I don't care | طز بالشغل — Screw work |
| أخ | akh | ouch / ugh | أخ! راسي — Ouch! My head |
| فلتة | falte | genius / unique | إنت فلتة — You're one of a kind |
| مفلس | muflis | broke (no money) | أنا مفلس — I'm broke |
| ياما | yaama | so much / plenty | ياما حكيتلك! — I told you so many times! |

## Jordanian Expressions of Time

| Expression | Meaning |
|-----------|---------|
| هلأ هلأ | right this second |
| بعد شوي | in a bit (could be 5 min or 2 hours) |
| بكرة إن شاء الله | tomorrow (might mean "never") |
| من زمان | ages ago |
| لسا | still / just now — لسا واصل = just arrived |
| قبل شوي | a little while ago |
| هالأيام | these days / lately |
